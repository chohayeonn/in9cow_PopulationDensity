<예측 탭>

<추천탭>

각 장소 별로 지금 현재 시간의 혼잡도가 어떤지도 확인이 가능하다.

<즐겨찾기>

로그인 했을 시에 사용이 가능하며, 로그인을 하지 않으면 로그인 후 기능을 이용할 수 있다는 문구가 뜬다.
